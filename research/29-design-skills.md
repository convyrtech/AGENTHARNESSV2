## landing-page-design (elaya) — частично

- **Берём идеи для `site-landing` в «Коде»:** одна цель → одна аудитория → одно действие; кнопка «глагол + что
  получит», не «Подробнее»; рядом с утверждением — доказательство; FAQ и снятие риска; состояния
  (наведение, нажатие, фокус, ошибка); подвал с политикой, своя 404, favicon, `og:image`.
- **Не берём вкус из части B:** фиксированные шрифты (Geist, Manrope), градиент на заголовке, «стеклянное»
  плавающее меню, обязательная секция «слова загораются при прокрутке». Если такой приём обязателен на каждой
  странице, все страницы становятся одинаковыми, то есть получается новый шаблон. К тому же это противоречит
  taste-skill (там градиенты, стекло и плавающее меню-пилюля запрещены) и нашему подходу «бренд владельца
  первым».

## design-to-motion (elaya) — на потом

Анимация карточек-бенто: сначала пусто, потом всё загружается, и каждый блок показывает, что он делает (график
читается, список пополняется). Таблица «блок → история» пригодится как идея для `motion/VOCAB.md`. Для альфы не
нужно.

## taste-skill — главное, что стоит взять

1. **Инвентарь предмета → фраза идеи → проверка конкурентом.** До вёрстки выписать 8–12 вещей, которые есть только
   у этого клиента (имя и его смысл, улица, числа, ограничение, ритуал, печатные вещи его мира). Затем фраза:
   «На этой странице **[вещь клиента]** становится **[приём]**». Проверка: подставить ближайшего конкурента — если
   фраза всё ещё верна, идея не годится. Плюс «одна живая штука» — что посетитель может сделать сам. Стоит только
   текста в промпте шага бриф/идея. По их слепым сравнениям, победители были построены на пункте инвентаря.
2. **Раздача направлений из библиотеки.** Модель сама выбирает средний по жанру вариант. Скрипт раздаёт 3 из 20
   направлений (композиция, шрифт, палитра, первый экран, секции) из библиотеки 202 сайтов, модель выбирает и
   объясняет выбор. Библиотека — JSON под MIT; можно взять с NOTICE.
3. **Правила, измеряемые кодом в браузере** (1440/768/390): заголовок не больше двух строк; один `h1` на первом
   экране и заголовок у каждой секции; равные внешние поля; секция не прижата к одному краю; нет пустых полос выше
   половины экрана; не больше одного почти пустого экрана; не меньше 4 настоящих картинок; при загрузке и
   прокрутке двигаются хотя бы 8 элементов. Плюс запреты: подписи над заголовком, моноширинный шрифт вне кода,
   нумерация 01/02/03, тонкие линии, градиенты, тени на неподвижном, мелкие капслоком подписи, одинаковые
   карточки с иконками, стекло. У нас часть этого — вопросы судье: Q10 «шаблонные приёмы», Q11 «пустые полосы».
   research/28 говорит: сначала проверка кодом, судья потом. Значит, Q10 и Q11 и правила выше — в `check.py`.
   Переписать на нашем Python + Playwright по их описанию; их Node-скрипт не тащить.
4. **Настоящие картинки из открытых архивов с лицензией.** `assets.mjs` ищет в Openverse, Wikimedia Commons,
   Art Institute of Chicago, Met, NASA и archive.org. По умолчанию — только лицензии с коммерческим
   использованием; скачивает, записывает источник и лицензию, печатает строку авторства для подвала. Правило
   честности: найденное фото показывает мир вокруг клиента и никогда не выдаётся за его товар, зал или людей. Наш
   `site-landing` сейчас разрешает только CSS и SVG — отсюда бедные страницы. Риск: доступность этих сайтов из
   России не проверена.
5. **Цикл «посмотри на снимки → критика → три правки», не больше трёх кругов.** У нас то же (судья плюс
   повторный раунд), сверить их рубрику `references/critique.md` с нашими 12 вопросами на вечерней калибровке.

## Оговорки

- Их «исследование 247 сайтов» оценивали 21 модель-рецензент по снимкам, не люди и не настоящие оценки Awwwards.
  Авторы прямо пишут это в `references/research.md` §1. Их цифры — ориентир, не доказательство.
- Часть запретов — личный вкус автора, и он это пишет. Например, моноширинные подписи и тонкие сетки на
  сайтах-победителях Awwwards встречаются чаще, а запрещены они как примета генерации.
- Любое правило вносить только с замером на нашем стенде «Дизайна» (A/B со слепым выбором), как остальное.
