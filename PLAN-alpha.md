# План альфы PRSLOY Desktop: 30 часов

Составлен 2026-10-25. Задача владельца: «полностью рабочая альфа приложения с автоустановщиком под Windows», вкладки
«Код» и «Дизайн», харнесс — сборник лучших практик из всего, что мы изучили (`research/00–16`, эксперименты E1–E9).
Работают параллельные агенты Claude Code, не человек руками.

## 1. Что такое «альфа готова»

Проверка — живая установка на Windows 10/11 у владельца:
1. Скачал `PRSLOY-Setup-0.1.0-alpha.N.exe` из GitHub Releases, поставил без прав администратора. SmartScreen
   предупредит («неизвестный издатель»): подписи нет, это ожидаемо для альфы.
2. Первый запуск: вставил ключ PRSLOY. Приложение проверило ключ и показало баланс или ошибку человеческими словами.
3. Выбрал папку проекта.
4. **Вкладка «Код».** Написал задачу словами и видит:
   - ход работы карточками: прочитал, поправил, запустил;
   - дифф;
   - стоимость хода в рублях;
   - кнопки «стоп» и «откатить ход».
5. **Вкладка «Дизайн».** «Сделай лендинг для …»:
   - вопросы приходят кнопками, листы выбора — картинками и видео, есть кнопка «как рекомендуешь»;
   - строка прогресса: что сейчас делается и сколько это займёт;
   - в конце превью страницы и папка с файлами.
6. Приложение само обновляется до следующей альфы.

**Не входит в альфу:**
- профили «Повседнев» и «Творчество», Telegram, совет экспертов;
- память с векторами;
- логотипы и 3D;
- подпись сертификатом, macOS.

## 2. Основа: берём готовое

Разведка 2026-10-25 (два агента, проверено клоном и сборкой). Все кандидаты под MIT.

| Основа | Плюсы | Минусы |
|---|---|---|
| **aletheics/zeno** — берём | Electron + React; Pi SDK в отдельном процессе; свой адрес и ключ провайдера; готовый NSIS-установщик Windows и настоящее автообновление (electron-updater); Node 22 и Python 3.12 в комплекте (нужен инструментам дизайна); словарь i18n; на Pi 1.4.0 собирается, 109/111 тестов | один автор; `main/index.ts` 5,7 тыс. строк; чужие картинки в темах (убираем) |
| Skitre/PiDeck | Tauri 2, установщик и подписанное обновление | на Pi 1.4 — 19 ошибок типов, +3–5 ч портирования |
| pi-gui | самый богатый интерфейс | Windows в бете (#254: падает через 4 с), без i18n, только уведомление об обновлении |
| Graphone, pi-desktop | — | без установщика или без своего провайдера, устарели |
| OpenCode desktop | готовый русский установщик | меняет ядро целиком (не Pi), 8,6 тыс. файлов |

Факты про Pi на Windows (`dist/utils/shell.js`):
- bash-тул ищет `shellPath`, потом Git Bash в Program Files, потом `bash.exe` на PATH. Это может оказаться WSL, и тогда команды тихо уходят в Linux. Без них тул падает.
- Решение: кладём в установщик PortableGit и задаём `shellPath`. На PATH агента добавляем шимы `python`/`python3` на Python из комплекта.
- Остальное: первый поиск качает fd/rg с GitHub (`PI_OFFLINE=1`); `pi --mode json` виснет на открытом stdin.

Отказ от Tauri из PLAN-v1: Electron-основа даёт установщик и обновление готовыми, а это главный риск срока.

## 6. Риски и что делаем

| Риск | Что делаем |
|---|---|
| Pi на Windows: bash-тул | по итогам разведки: Git Bash в комплекте или PowerShell-тул |
| Инструменты дизайна на Python + Playwright | портативный Python скачивается при первом заходе во «Дизайн»; браузер — установленный Edge (`channel="msedge"`), WebKit по требованию |
| Поставщики a6 рвут поток | прокси надёжности; в проде — на нашем шлюзе |
| Нет подписи | альфа без подписи: инструкция «Подробнее → Выполнить в любом случае» |
| Лимит Claude | облачные сессии только на дорожках W0–W5; разведку и проверки делают дешёвые подагенты |
| Сборки только в Actions | репозиторий публичный: Windows-минуты бесплатны; логи читаем через API |
