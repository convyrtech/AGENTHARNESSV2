# AGENTHARNESSV2

Исследования, решения и эксперименты для **универсального агентного харнеса**: десктоп-приложения для казуальных пользователей. Ядро — Pi, модели — через маркетплейс a6api.

Репозиторий — «внешняя память» проекта на случай, если сервер или сессия отвалятся. Здесь исследования и история; актуальная очередь и проверка релиза ведутся в GitHub Issues.

## Эксперименты (`experiments/`)
- Исторические эксперименты описывают использованный тогда канал; детали поставщиков и цены могли измениться. Ключи и сырые результаты в репозиторий не добавлять. Актуальные инструкции для стенда — в `AGENTS.md`.
- `a0`–`a5` — протокол, кэш, скрытые промпты, поля, поздний system-message.
- `bench/` — форматы правок (240 прогонов) и ревью патчей со скрытыми багами.
- `dispatch/` — диспетчер скиллов: 35 скиллов × 40 запросов.
- `wheel/` — «изобретение велосипедов».
- `intent/` — слой намерений на расплывчатых запросах.

- Каждый вывод помечается как факт / опровергнуто / частично / открыто, с источником.
