# Проект: сайт PRSLOY (prsloy.online)

Ты агент в десктоп-приложении PRSLOY. С тобой говорит владелец проекта, обычный человек, не дизайнер.

## Плейбук «страница сайта»
Любую страницу делаем строго по дизайн-пайплайну: `design-pipeline/AGENTS.md` (прочитай его первым, целиком).
Первая команда: `python3 -I design-pipeline/tools/flow.py --page design/<page> --init`, дальше делай ровно тот шаг,
который называет `python3 -I design-pipeline/tools/flow.py --page design/<page>`. После шага запускай flow.py снова.

## Сначала материалы, потом вопросы
Если владелец ещё не прислал материалы, первое сообщение ему — только просьба одной строкой: «пришлите, что есть:
скрины, логотип, ссылку на кабинет или сайт». Вопросы шага 0a задавай после материалов. Варианты настроения выводи из
того, что прислал владелец (его цвета, шрифты, характер экранов), а не из известных брендов.

## Откуда брать вкус: эталоны и референсы не из памяти
Источник — каталог роликов, сделанных на Opus 5.5: `etalons/skillry-index.json` (418 роликов; у каждого категория,
стек, промпт, ссылка на страницу). Известные сайты из памяти (Stripe, Linear, Vercel, Resend и т. п.) кандидатами
не предлагай.
1. Ищи в индексе по смыслу бренда владельца: материал, фактура, характер, приёмы движения (поиск по `prompt`,
   `category`, `tech`). Отбери 6–8, по каждому посмотри кадры, оставь 3 РАЗНЫХ.
2. Кадры кандидата: `python3 -I etalons/etalon_video.py <slug> design/<page>/01-cands/<slug>` — 12 кадров с
   метками времени, лист `contact.png`, полный промпт `prompt.txt`.
3. Лист владельцу на шаге 1: `compare_sheet.py --engine chromium --variant <contact1.png> --variant <contact2.png>
   --variant <contact3.png> --out design/<page>/01-candidates.png`.
4. Выбранный эталон: его 12 кадров скопируй в `01-frames/`. Разбор в `01-teardown.md` сделай покадрово: что даёт
   вау (кадр, время) → на чём сделано (по кадрам и промпту) → берём / нет и почему. В паспорте
   «Эталон: <ссылка на страницу ролика>».
5. Референсы на шаге 3 ищи там же. Живой сайт можно добавить только для раскладки страницы, со своим кадром.

## Окружение (важно)
- Во всех скриптах указывай `--engine chromium` (gate.py, compare_sheet.py, visual_gate.py, storyboard.py, page_judge.py).
- Интернет есть, скрипты с Playwright ходят на внешние сайты как обычно.
- Сообщения владельца приходят в файл `owner/messages.jsonl` (его пишет приложение, не ты). В паспорте STATUS.md укажи строку `- Канал владельца: owner/messages.jsonl`.
- Чтобы спросить владельца, закончи свой ход сообщением ему (по правилам `design-pipeline/templates/OWNER-MESSAGE.md`). Приложение покажет его владельцу, ответ придёт следующим сообщением.
- Файлы, которые пришлёт владелец, появятся в папке `materials/`.
- Python запускай как `python3 -I`.
- Ничего не устанавливай в систему (apt, pip, playwright install) без разрешения владельца.
- Не запускай другие ИИ-программы с компьютера (claude, codex, gemini и т. п.): это чужие аккаунты и деньги.
- Подагент (судья, проверка) — только через приложение: `pi -p --no-session --tools read --model a6/claude-opus-5-5 "<задание>"`.
  Судья — модель другой семьи, чем ты. Его ответ дословно сохраняй в файл, как требует шаг.
