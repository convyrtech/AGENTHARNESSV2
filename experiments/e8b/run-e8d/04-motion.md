# Motion Contract — prsloy.online, лендинг «ключ и лимит»

> Заполнить ДО кода. `tools/motion_probe.py` сверяет реализацию с этим файлом.
> Основа — эталон `heyiamnick-119558` (01-teardown.md): запертая камера, одно движение за раз, пружина с критическим
> демпфированием, шаг 120 BPM = 500 мс на такт. Референсы 1, 2, 3 из 03-references.md задают три приёма.

## 1. Trigger
- Тип: `load/intro` для первого экрана + `scroll-progress 0..1` для остальных блоков (`in-view` на 0.35).
- Диапазон/условие: интро 0–1400 мс от `DOMContentLoaded`; блок «Лимит» — progress 0..1 по вьюпорту элемента
  (scroll Y от `top - innerHeight` до `top`); блоки «Шаги» и «Кабинет» — `in-view` один раз, без повтора при
  обратном скролле.

## 2. Объекты (что движется независимо)
- Слой `paper` — фон и сетка чертежа: не двигается, только `opacity` 0→1 за 240 мс (глубина 0).
- Слой `rules` — три линейки-правила первого экрана: `transform: scaleX()` от 0 к 1, origin left (глубина 1).
- Слой `title` — заголовок и подпись: `transform: translateY()` + `opacity` (глубина 1).
- Слой `stamp` — красный штамп «ключ»: `transform: scale()` + `opacity`, приходит последним (глубина 1.4).
- Слой `counter` — счётчик лимита: `stroke-dashoffset` у шкалы и число через `textContent` (глубина 2, единственный
  JS-слой).
- Слой `screen` — снимок кабинета в рамке: `transform: translateY()` + `opacity` (глубина 1).

## 3. Spec-таблица (сердце контракта — measurable)

| progress / время (ms) | визуальное состояние | ключевое свойство + значение | слой | easing |
|---|---|---|---|---|
| 0.0 / 0ms | пустая бумага, заголовка нет | `opacity: 0`, сетка `opacity: 0` | paper | — |
| 0.0 / 120ms | сетка чертежа проявилась | `opacity: 1` | paper | cubic-bezier(0.22, 1, 0.36, 1) |
| 0.0 / 240ms | линейки растут слева направо | `transform: scaleX(0) → scaleX(1)`, `transform-origin: left` | rules | cubic-bezier(0.22, 1, 0.36, 1) |
| 0.0 / 360ms | заголовок поднимается на место | `transform: translateY(18px) → translateY(0)`, `opacity: 0 → 1` | title | cubic-bezier(0.22, 1, 0.36, 1) |
| 0.0 / 620ms | штамп падает и садится | `transform: scale(1.18) → scale(1)`, `opacity: 0 → 1` | stamp | spring `{stiffness: 520, damping: 48}` |
| 0.0 / 1400ms | интро закончилось, страница стоит | все слои в конечном состоянии, ни одного `animation` в `running` | все | — |
| 0.25 / 900ms | блок «Шаги» вошёл в кадр | рамки: `opacity: 0 → 1`, `translateY(24px) → 0`, задержка 90 мс на шаг | steps | cubic-bezier(0.22, 1, 0.36, 1) |
| 0.5 / 1200ms | шкала лимита дошла до 8 из 10 | `stroke-dashoffset: 100% → 20%` (8/10), число `0 → 8` | counter | linear |
| 0.85 / 1500ms | блок «Кабинет»: снимок встал в рамку | `translateY(32px) → 0`, `opacity: 0 → 1`, `clip-path: inset(0 0 12% 0) → inset(0)` | screen | cubic-bezier(0.22, 1, 0.36, 1) |
| 1.0 / 1800ms | финальный кадр блока | конечные значения, `will-change` снят | все | — |

## 4. Easing / spring (точные значения, не «ease-out»)
- Появление и подъём (сетка, линейки, заголовок, рамки шагов, снимок кабинета) → `cubic-bezier(0.22, 1, 0.36, 1)`,
  500–700 мс, как такт 120 BPM эталона.
- Штамп → spring `{stiffness: 520, damping: 48}` (критическое демпфирование, перелёта нет).
- Шкала лимита и число → `linear` 600 мс: цифра обязана читаться как отсчёт, не как украшение.

## 5. Path (есть)
- Штамп: прямая сверху вниз 12 px с масштабом 1.18 → 1, без поворота (бумага лежит ровно).
- Линейки: только по X, `transform-origin: left`; траекторий по дуге нет.

## 6. Texture (характер движения)
- Механический и точный: чертёж, а не танец. Одно движение за раз, паузы между тактами, без инерции после остановки.

## 7. Interrupt-поведение
- Быстрый реверс скролла: `scroll-progress` следует за скроллом напрямую (без догоняющей инерции), шкала и число
  реверсируются.
- `in-view` блоки: доигрывают один раз, при обратном скролле остаются в конечном состоянии.
- Повторный hover на кнопке «Войти»: доигрывает до конца, повторный запуск не копится.

## 8. Перф-бюджет (обязательно; мобилка = приоритет)
- Target FPS (mid-mobile): `>= 55`
- Frame time: `< 18ms`
- Layout-shift во время анимации: `0` (двигаем только `transform`, `opacity`, `stroke-dashoffset`)
- Макс. одновременно анимируемых слоёв: `3`
- Один `requestAnimationFrame` на страницу, чтение `scrollY` один раз за кадр, запись в `style` батчем.
- Эти значения → пороги `THRESHOLDS` в `tools/motion_probe.py` (`min_fps 55`, `max_long_frames 3`, `max_cls 0.02`).

## 9. reduced-motion
- При `prefers-reduced-motion: reduce`: интро не играет, страница сразу в конечном состоянии (все `opacity: 1`,
  `transform: none`, шкала на 8/10, число 8); `scroll-progress`-анимации отключены, число и шкала ставятся один раз.
- Бесконечных анимаций нет ни в одном режиме.

## 10. Acceptance (как поймём, что готово)
- `python -I tools/motion_probe.py --url http://127.0.0.1:8000/ --trigger load --out artifacts/motion` → verdict PASS
  (сначала `python3 -m http.server 8000` из папки `site/prsloy`).
- Числа `getAnimations()` сходятся со Spec-таблицей (easing, duration, props): `cubic-bezier(0.22, 1, 0.36, 1)`,
  240/360/620/900/1200/1500 мс, свойства `transform` и `opacity`.
- Перф-бюджет соблюдён на 390×844: FPS ≥ 55, long frames ≤ 3, CLS ≤ 0.02.
