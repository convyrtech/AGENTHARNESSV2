# Набор «Исследовать» (R0, research/26 §4.10–4.11)

30 вопросов с эталоном: 15 про Россию (ставки, налоги, курсы, цены российских API), 15 международных (версии,
лицензии, цены и условия поисковых API, свежие события). Ловушки — те, на которых модели врут: прошлый год, устаревшие
цифры, «предложено» вместо «принято», маркетинг продавца.

| Файл | Что |
|---|---|
| `questions.json` | Вопросы. `live` — эталон берётся из первоисточника в момент оценки; иначе застывший эталон с источником, дословной цитатой и датой проверки (2026-10-25) |
| `live.py` | Живые эталоны: ключевая ставка и курсы ЦБ, Node LTS, Python, npm, ядро Linux |
| `check_refs.py` | Перед прогоном: живые эталоны открываются, цитаты застывших ещё лежат на своих страницах |
| `score.py` | Метрики по `results.jsonl` любого исполнителя (формат — в начале файла) |
| `run_builtin.py` | База B: встроенный поиск моделей через шлюз (`web_search_options`) и проверка каналов `/v1/tools/search|fetch` |
| `test_score.py` | Тесты оценки без сети |

## Метрики (`score.py`)

- **Точность ответа**: эталон проверяется кодом по нормализованному тексту (числа без пробелов, запятая → точка,
  ё → е). Для открытых вопросов (`judge`) код проверяет обязательные пункты, полноту оценивает судья другой семьи.
- **Цитаты**: доля источников, чья дословная цитата нашлась в тексте страницы (без регистра, разметки, кавычек, ё/е;
  не короче 3 слов или 20 знаков). Источник без цитаты не засчитывается.
- **Живые ссылки**: ответ 200/3xx. **Свежесть**: доля источников с датой; запросы с прошлым годом, которого нет в
  вопросе. **Цена и время**: p50 и p90 на вопрос.

## Команды

```
cd experiments/research
python3 check_refs.py                                   # эталоны живы? (r14, i09 — сверить руками)
python3 run_builtin.py probe                            # есть ли /v1/tools/search|fetch и встроенный поиск у gpt, opus, grok
python3 run_builtin.py run --model claude-opus-5-5 --out runs/builtin-opus.jsonl
python3 score.py runs/builtin-opus.jsonl --out runs/builtin-opus
```

Ключ — `experiments/.a6key` (или `--key-file`), адрес — `--base` (по умолчанию `https://a6api.com`). `run` дописывает
файл и пропускает готовые вопросы, его можно перезапускать.

База A (opus с простыми `web_search`/`web_fetch`) появится вместе с инструментами R1.
