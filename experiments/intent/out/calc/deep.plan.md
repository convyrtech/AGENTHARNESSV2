# Спецификация: калькулятор экономии на AI-сервисе

## 1. Реальная цель
Пользователь хочет конверсионный инструмент, который превращает интерес в решение о покупке. Калькулятор должен показать конкретную денежную выгоду и создать момент осознания: "я теряю деньги прямо сейчас". Это не информационный виджет — это инструмент продаж.

## 2. Что сделает профессионал

**Персонализация по сценарию использования:** вместо универсального калькулятора — 3-4 готовых профиля (стартап, агентство, корпорация, разработчик) с предзаполненными реалистичными цифрами. Пользователь видит себя, кликает — сразу результат.

**Психологические триггеры:** показывать экономию не только в месяц, но и в год + визуализация "на что хватит сэкономленного" (10 дополнительных сотрудников, 500 часов работы дизайнера). Добавить таймер окупаемости: "окупится за 4 дня".

**Социальное доказательство прямо в калькуляторе:** после расчёта — микро-кейс похожей компании: "Компания X с таким же объёмом экономит $2,400/мес уже 6 месяцев".

## 3. Готовые решения

**Фреймворк:** React + shadcn/ui или Tailwind UI (готовые компоненты слайдеров, карточек). Для анимаций — Framer Motion.

**Паттерн калькулятора:** модель ProfitWell/Paddle pricing calculator — слайдеры с живым пересчётом, прогресс-бар экономии, цветовое кодирование (красный→зелёный).

**Формула ценообразования:** benchmark OpenAI API vs ваш сервис. Взять публичные цены GPT-4/Claude, добавить реальный markup (обычно 20-40% на API-resale).

## 4. Техническое задание исполнителю

**Структура:**
- Заголовок: "Сколько вы переплачиваете за нейросети?"
- 3 слайдера: запросов/день, средняя длина запроса (токены), модель (GPT-4/Claude/Gemini)
- Карточка результата: текущие расходы | экономия с нами | экономия за год
- CTA: "Начать экономить" + "Показать детальный расчёт" (раскрывает breakdown)

**Стиль:**
- Палитра: тёмный фон (#0A0E27), акцент — electric violet (#7C3AED), позитивный зелёный для экономии (#10B981)
- Типографика: Inter для цифр (tabular numbers), градиентный жирный шрифт для суммы экономии
- Микроанимации: цифры считаются с easing, прогресс-бар заполняется, конфетти при >$1000 экономии

**Контент:**
- Реалистичные дефолты (не 10 запросов, а 5000/день)
- Breakdown: "стоимость у OpenAI", "наш тариф", "скидка за объём", "итого"
- Дисклеймер мелким шрифтом: расчёт примерный, точная цена — после аудита

## 5. Критерии качества

**Должно быть:**
- Результат виден без скролла, цифры читаются за 2 секунды
- Работает на мобильном (слайдеры удобные, цифры крупные)
- Честные расчёты (проверить формулы на реальных тарифах конкурентов)
- Загружается мгновенно (<1сек), zero dependencies в бандле

**Избегать:**
- Абстрактных процентов вместо денег
- Слишком агрессивных обещаний ("экономьте 90%")
- Множества полей ввода — максимум 3-4 параметра
- AI-штампов в тексте: "раскройте потенциал", "революционный", "инновационный"
