## Анализ задачи и профессиональный план

**1. Истинная цель**
Вам нужен стабильный поток квалифицированных лидов (разработчиков/компаний) для вашего API-сервиса, чтобы достичь critical mass пользователей и доказать product-market fit. Без бюджета единственный актив — ваше время и экспертиза.

**2. Что сделал бы топовый growth-специалист**
- **Developer advocacy через código vivo**: не писать о API, а публиковать рабочие integration examples с топовыми фреймворками (Next.js + ваш API, FastAPI + ваш API). Репозитории на GitHub с тегами "starter", "boilerplate" ранжируются выше статей.
- **Reverse engineering конкурентов**: проанализировать через SimilarWeb/BuiltWith, где их пользователи собираются (Stack Overflow теги, Discord серверы, subreddits). Прийти туда с решениями, не спамом.
- **Создать comparison page**: "Ваш API vs Twilio/Stripe/etc" с честными trade-offs. Это SEO-магнит и trust signal одновременно.

**3. Проверенные инструменты и паттерны**
- **Product Hunt без денег**: запуск в сообществе Ship, pre-launch página за 2 недели до основного запуска
- **Dev.to + Hashnode**: кросспостинг technical tutorials (используйте их канонические URL для SEO)
- **Apidog, Postman Public Workspaces**: публикуйте ready-to-use коллекции вашего API
- **Indie Hackers, HackerNews Show HN**: формат "Show HN: API для X за 10 строк кода"
- **Фреймворк контента**: Jobs-to-be-Done → найдите 3 задачи разработчиков, которые ваш API решает за минуту вместо часа

**4. Спецификация для исполнителя**

**Структура 90-дневной кампании:**
- Недели 1-2: 5 code examples на GitHub (README с GIF демо)
- Недели 3-6: 8 tutorial-статей (Dev.to, Hashnode, Medium) — каждая решает одну боль
- Недели 7-10: Комментирование 50+ relevant тредов на Reddit/SO со ссылками на ваши примеры
- Недели 11-12: Product Hunt launch + outreach в 20 developer newsletters

**Тон:** Конкретный, без хайпа. Формат "Problem → 10 lines of code → Result". Никаких "revolutionize", "game-changing".

**5. Критерии качества**
✅ Каждый пример запускается за <2 минуты  
✅ 80% контента — код/скриншоты, 20% — текст  
✅ Measurement: UTM-метки на всех ссылках, трекинг sign-ups по источникам  

❌ Избегать: generic посты "Introducing our API", falsos case studies, просьбы "check out my project" без контекста.
