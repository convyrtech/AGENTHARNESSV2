## Анализ задачи и профессиональный подход

**1. Реальная цель клиента**
Мастеру нужен работающий инструмент конверсии: посетители должны не просто смотреть, а записываться на услугу. Это значит — страница решает бизнес-задачу: заполнить календарь, снизить процент "подумаю" и отсеять неподходящих клиентов до звонка.

**2. Что сделал бы топовый специалист (чего не попросили)**

- **Встроил бы social proof системно**: не просто отзывы списком, а конкретные фото "до/после" с именами клиентов, цифрами ("3 года хожу к Анне") и акцентом на повторных записях — это снимает барьер доверия сильнее текста.

- **Спроектировал бы микро-воронку прогрева**: первый экран не с "Записаться", а с тестом/квизом ("Какой маникюр вам подойдёт?") или визуальным выбором стиля работ — человек вовлекается, потом легче конвертируется.

- **Заложил бы страховки от "потерь"**: pop-up при закрытии вкладки с быстрой формой, автоматические напоминания в Telegram после заявки, интеграция с Yclients/Dikidi для синхронизации окон записи в реальном времени.

**3. Проверенные решения (что использовать)**

- **Платформа**: Tilda (блок T123 для записи) или Readymag — встроенная интеграция с календарями.
- **Форма записи**: Calendly / Yclients виджет — клиент видит свободные слоты, сам выбирает время.
- **Паттерн убеждения**: PAS-структура (Problem-Agitate-Solution): "Устали от сколов через 3 дня?" → детали боли → "Покрытие, которое держится 4 недели".
- **Визуальный фреймворк**: Instagram-эстетика (сетка 3×3 для портфолио), палитра из реальных фото работ мастера (pipette tool).

**4. Спецификация для исполнителя**

**Структура (5 блоков):**
1. Hero: имя мастера, ёмкий оффер ("Маникюр, который переживёт отпуск"), кнопка + фото рук крупным планом.
2. Портфолио: сетка 9–12 работ, фильтр по стилям (классика/дизайн/укрепление).
3. Доказательства: 3–4 отзыва с фото клиента + скриншот из переписки.
4. Услуги + цены: таблица, якорное ценообразование (самое дорогое первым).
5. Форма записи: интеграция календаря, поле для комментария, WhatsApp/Telegram кнопки.

**Стиль:**
- Палитра: нюдовые + один акцент из работ (часто коралл/пыльная роза).
- Шрифты: PT Sans/Montserrat (кириллица, вебсейф).
- Tone of voice: тёплый, конкретный ("Я работаю на японских материалах CND" вместо "качественные материалы").

**5. Критерии отличного результата**

✓ Кнопка записи видна без скролла на мобильном.  
✓ Время загрузки <2 сек (сжатые фото через TinyPNG).  
✓ В форме нет поля "Сообщение" — только конкретные: дата, услуга, контакт.  
✓ Ноль клише AI: "индивидуальный подход", "высокое качество", "уютная атмосфера".

**Типичные провалы:** слайдер портфолио (не кликают), длинный текст "о себе", отсутствие цен (клиент уходит), форма без подтверждения отправки.
