# Профессиональный план монетизации ИИ-навыков

## 1. Истинная цель
Вы хотите создать устойчивый источник дохода через навыки работы с ИИ. Реальная задача — найти пересечение между вашими возможностями, рыночным спросом и конкурентным преимуществом, которое сложно скопировать.

## 2. Что делает профессионал (чего вы не спросили)

**Выбирает специализацию вместо "всего понемногу"**: не "работаю с нейронками", а "автоматизирую рекрутинг через ИИ для B2B" или "создаю персонализированные email-цепочки для e-commerce". Узкая ниша = меньше конкурентов, выше чек.

**Строит систему, а не продаёт часы**: упаковывает решения в повторяемые продукты (шаблоны промптов, настроенные GPT, автоматизации в n8n/Make), которые масштабируются без вашего времени.

**Создаёт доказательства до продаж**: делает 2-3 кейса бесплатно/за символическую плату, документирует результаты в цифрах (сэкономили 15 часов в неделю, выросла конверсия на 23%), использует как портфолио.

## 3. Проверенные пути и инструменты

- **Курсы-образцы**: "The AI Solopreneur" (Justin Welsh), "AI Business Blueprints" (Liam Ottley) — не копировать, а изучить структуру позиционирования
- **Платформы для старта**: Upwork (фильтр "AI automation"), Fiverr Pro (после портфолио), Contra, Twitter/X для прямых клиентов
- **Технический стек**: Claude/GPT API + n8n/Make.com + Airtable/Notion — стандарт для автоматизаций без кода
- **Фреймворк презентации**: Jobs-to-be-Done (какую работу клиент "нанимает" ИИ делать) + ROI-калькулятор

## 4. Техзадание исполнителю

**Действия на первые 14 дней:**

1. **Аудит навыков** (день 1-2): составить список из 10 задач, которые вы уже решали с ИИ; выбрать 3 самые ценные для бизнеса
2. **Выбор ниши** (день 3-4): найти 5 сообществ/форумов целевой аудитории, изучить 50+ запросов про боли
3. **Создание оффера** (день 5-7): описать одну конкретную услугу в формате "превращаю [проблема] в [результат] за [срок] через [метод]"
4. **Первый кейс** (день 8-14): сделать бесплатно для одного клиента, зафиксировать метрики "до-после", оформить на лендинге/в PDF

**Критерии качества оффера:**
- Решает измеримую боль (не "улучшу процессы", а "сокращу время обработки заявок с 2 часов до 15 минут")
- Цена привязана к ценности, а не часам (от 30,000₽ за проект, а не "2000₽/час")

## 5. Проверка качества

**Что должно быть true:**
- За 30 секунд объяснения любой из целевой аудитории говорит "это про меня"
- Есть 1-2 доказательства результата (скриншоты, отзыв, видео)
- Оффер продаётся без вашего участия (через лендинг/соцсети)

**Типичные провалы:**
- Позиционирование "делаю всё с ChatGPT" (нет фокуса → нет премиум-цены)
- Отсутствие social proof (клиенты не верят без доказательств)
- "Консалтинговая" модель вместо продуктовой (упёрлись в потолок 200 часов/месяц)
