## План: Dashboard мониторинга токенов клиентов

**1) Настоящая цель**
Пользователю нужна система контроля расходов AI API для управления бюджетами клиентов и выявления аномалий потребления. Результат: прозрачность затрат, быстрое принятие решений о лимитах и масштабировании.

**2) Что сделал бы топовый специалист**
- **Реал-тайм алерты**: не просто показать цифры, а настроить пороги (клиент превысил 80% месячного лимита → уведомление)
- **Trend analysis**: сравнение с предыдущими периодами, прогноз расхода на конец месяца по текущей динамике
- **Drill-down архитектура**: клик на клиента → разбивка по моделям (GPT-4 vs Claude), по типам запросов (chat/completion/embedding), по временным пикам

**3) Проверенные решения**
- **Recharts** (React) или **Chart.js** — готовая визуализация с адаптивностью
- **TanStack Table** — сортировка, фильтрация, пагинация из коробки
- **Паттерн Dashboard Cards** (Stripe, Vercel стиль) — метрики в карточках с иконками и процентными изменениями
- **Color semantics**: зелёный (в норме), жёлтый (приближается к лимиту), красный (превышение) — универсальная система
- **Mock данные через Faker.js** или **MSW** для реалистичных сценариев

**4) Спецификация для исполнителя**

**Структура:**
- Header: период (selector), total spend, средний расход на клиента
- Cards grid: Top-5 клиентов по расходу с мини-графиками
- Main table: все клиенты (имя, токены за период, стоимость, динамика, статус лимита)
- Timeline chart: расход токенов по дням (stacked по клиентам)

**Арт-направление:**
- Палитра: тёмная тема (slate background), акценты cyan/emerald для данных
- Типографика: Inter/SF Pro для цифр (tabular-nums), чёткость метрик
- Motion: subtle hover states, skeleton loaders при загрузке

**Данные (придумать):**
15-20 клиентов, 30-дневный период, разброс 50K–5M токенов, 2-3 клиента близко к лимиту, 1 превысил.

**5) Критерии качества**
✓ Главные метрики видны за 2 секунды без скролла  
✓ Понятно, кто требует внимания (цветовое кодирование)  
✓ Таблица сортируется по любой колонке  
✗ Избегать: generic "loading...", отсутствие единиц измерения, перегруз графиками без инсайтов
