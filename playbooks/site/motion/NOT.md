# Что в движении не берём

Стоп-лист из разбора The Raki (`REFS.md` §3, 2026-09-30), без привязки к бренду. Агент вписывает его в каждое задание,
судья проверяет по снимкам.

| Что | Почему |
|---|---|
| Ореолы, свечение, светящиеся точки | Выглядит как дешёвый «ИИ-шоурил». Вместо ореола — тонкое кольцо |
| Тёмные техно-фоны, неон, глобусы, частицы | Шаблон «тёмный SaaS». Фон берётся только из бренда |
| Градиенты на тексте и элементах | Дешёвый хайп; даже авторы роликов запрещали их в промптах |
| `filter: blur` в движении, motion blur | Дорого на телефоне, мылит текст |
| Хроматическая аберрация, зерно шейдером, glitch | Шум и нагрузка |
| Мягкий край шторки, нарезка полосами | Мельтешит. Край шторки — тонкое кольцо или чистый круг |
| Мультяшные крены, заметный перелёт, «bouncy» | Перелёт ≤4%, пружина только у главного предмета |
| Печать заголовков по буквам, деформация слов линзой | Ломает чтение и кернинг. Текст виден с 0 мс |
| Счёт с нуля, появление текста с задержкой | Числа и текст читаются сразу; число «доезжает» к значению, которое уже стоит в HTML |
| Живой WebGL / three.js / GLB со светом и тенями | Не держит 55 кадров на среднем телефоне. Замена: 2.5D-слои или последовательность кадров |
| Рой из сотен элементов дольше 3–5 с | Перегруз. Максимум один короткий фрагмент |
| Бесконечные пульсации вне экрана | Ставить на паузу, пока элемент не виден |
| Скриншоты интерфейса картинкой вместо живого элемента | Это копия, а не дизайн (E8d, владелец: «пнг это треш») |
| Пояснения очевидного прямо на странице («нажмите, чтобы…», «это пример анимации») | Засоряет; подсказка только там, где у человека реально возникнет вопрос |
