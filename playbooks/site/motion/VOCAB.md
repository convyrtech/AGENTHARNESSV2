# Словарь приёмов движения

Готовые приёмы для страниц сайта. Агент не ищет эталоны заново на каждой странице, а выбирает 2–3 приёма отсюда и
ставит готовый компонент из `motion.js`. Облик (цвета, шрифты, линии) всегда берётся из бренда владельца. От
источников берём только **грамматику движения**: что движется, в каком порядке, с каким темпом.

Источник словаря: разбор владельца для The Raki (`convyrtech/12354`, `docs/redesign/v2/motion-refs/skillry/REFS.md`,
2026-09-30). 20 роликов из галереи [skillry / Opus 5.5](https://skillry.dev/ai-videos/opus-5-5) разобраны покадрово.
Тайминги ниже из того разбора. Облик гжели убран, имена приёмов сохранены.

Метки: **[П]** — проверено по кадрам или коду; **[Пр]** — оценка по кадрам, на телефоне не замерено.
Колонка «Компонент» — имя в `motion.js` (пусто — приём пока только описан).

Все компоненты устроены одинаково: **кадр = функция одного числа t от 0 до 1**. Поэтому любой приём можно
проиграть один раз при появлении на экране, привязать к прокрутке, снять в любой точке для проверки и записать в видео
без ручной подгонки.

## Как выбирать

- На страницу **2–3 приёма**, не больше. Один главный (обычно 1, 4 или 5) и 1–2 служебных (6, 8, 13, 14).
- Приём должен **что-то значить** на странице: штамп ставится на выданный ключ, рельс ведёт по реальным шагам,
  число показывает реальный лимит. Украшение без смысла не ставим.
- **Одно правило-метафора на всю страницу** (см. `PROMPT-TIPS.md`): например, «одна линия, которая не рвётся: точка →
  кольцо → предмет». Тогда приёмы складываются в цельный рассказ, а не в набор эффектов.
- Тропа (5) и рельс (6) — про одно и то же: берём один из двух. На телефоне естественнее тропа, на компьютере рельс [Пр].

## Правила для всех приёмов

- Текст, цифры и кнопки видны и нажимаются с 0 мс. Движение не прячет содержимое: без JS и при
  `prefers-reduced-motion` страница стоит в финальном состоянии.
- Только `transform`, `opacity`, `stroke-dashoffset`, `clip-path`. Без `filter: blur`, без анимации размеров вёрстки.
- Бесконечные движения и сцены вне экрана на паузе (вкладка скрыта или элемент не виден).
- Интро прерывает только прокрутка, не касание. Финальное состояние ставится руками, без `commitStyles` (WebKit
  записывал неверное значение, разбор The Raki 2026-09-30).
- Одна кривая бренда на 80% движений. Перелёт не больше 4%, пружина только у главного предмета.
- Что не берём — `NOT.md`.
