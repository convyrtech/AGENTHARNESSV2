# motion — готовые приёмы движения для страниц

Агент не изобретает анимацию и не ищет эталоны заново. Он выбирает 2–3 приёма из словаря, показывает владельцу лист
приёмов в цветах его бренда и ставит готовые компоненты. Источник словаря — покадровый разбор 20 роликов skillry
для The Raki (см. `VOCAB.md`).

| Файл | Что это |
|---|---|
| `VOCAB.md` | 15 приёмов: когда брать, механизм, темп, риск на телефоне, компонент |
| `vocab.json` | то же для инструментов: опции и разметка каждого компонента |
| `NOT.md` | стоп-лист движения, вписывается в каждое задание |
| `PROMPT-TIPS.md` | как ставить задачу сборщику (одно правило-метафора, запреты, сетка времени…) |
| `motion.js`, `motion.css` | 11 компонентов без библиотек: ringHead, stepsRail, odometer, stamp, slotLift, trailDot, shutter, morph, dotCascade, lineWord, director |
| `brands/*.css` | примеры токенов бренда (PRSLOY, The Raki) |
| `demo/index.html` | все приёмы на одной странице; `?brand=raki`, `?move=ring`, `?t=0.4` |
| `tools/moves_sheet.py` | лист приёмов и короткие видео для владельца |
| `tests/check_motion.py` | проверка приёмов на любой странице |
| `tools/skillry-index.json`, `etalon_video.py` | каталог роликов skillry (418 живых) и нарезка кадров — только для пополнения словаря |

## Как поставить приём на страницу

1. Подключить `motion.css` и `motion.js`, задать токены бренда на `:root`:
   `--m-ink`, `--m-accent`, `--m-paper`, `--m-line`, `--m-stroke`, `--m-ease`, `--m-num` (см. `brands/prsloy.css`).
   Умолчания `motion.css` имеют нулевую специфичность и бренд не перебивают.
2. Разметить элемент: `data-move="<компонент>"`, опции в `data-opts='{"dur":1100}'`, разметка детей — в `vocab.json`.
   Главному приёму страницы — `data-signature="<имя>"` (его ищет проверка харнесса).
3. Запуск: `data-trigger="inview"` (по умолчанию, один раз при появлении), `"load"` (после загрузки, рвёт только
   прокрутка) или внутри сцены `data-move="director"` с `data-at="0.2-0.6"` — тогда приём ведёт прокрутка.
4. Кнопка-морф запускается по клику сама или `Motion.get(el).run()`.

Пример:
```html
<div data-move="ringHead" data-opts='{"pad":24}' data-signature="ring"><span class="big">32,41 ₽</span></div>
<ol data-move="stepsRail"><li>Войдите</li><li>Получите ключ</li><li>Вставьте адрес</li></ol>
<span class="stamp" data-move="stamp" data-delay="250">КЛЮЧ ВЫДАН</span>
```

## Режимы
- Без JS и при `prefers-reduced-motion` страница стоит в финальном состоянии.
- `?t=0.4` или `Motion.seek(0.4)` замораживает все приёмы в точке t — для проверок, листов и видео.
- Бесконечные движения на паузе вне экрана и на скрытой вкладке.

## Проверки
```
python3 -m http.server 8311            # из этой папки или из папки сайта
python3 -I tests/check_motion.py "http://127.0.0.1:8311/demo/index.html?brand=prsloy"
python3 -I tools/moves_sheet.py --base http://127.0.0.1:8311/demo/index.html --brand <бренд> --out <папка> --video
```
`check_motion.py`: нет ошибок в консоли; reduced-motion = финал; каждый приём двигается; текст не пропадает; p95 кадра
< 20 мс на телефоне при замедлении процессора ×4; анимируются только transform / opacity / stroke-dashoffset / clip-path.
Проверено 2026-10-24: оба бренда, 390 и 1440, Chromium и WebKit — PASS, p95 16,7–16,8 мс.
