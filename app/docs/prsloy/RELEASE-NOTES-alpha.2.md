# PRSLOY 0.1.0-alpha.2 — что нового

Вторая пробная версия. У кого стоит alpha.1, программа обновится сама: внизу появится «Обновление готово —
перезапустить». Ключ, проекты, чаты и память при этом остаются на месте.

## PRSLOY для Linux

Теперь есть версия для Linux. Проверена на Ubuntu 24.04 (компьютеры с обычным процессором Intel или AMD,
x86-64). Скачайте один из двух файлов.

- **Файл .deb — проще всего (Ubuntu, Debian, Linux Mint).** Скачайте `PRSLOY-…-linux-amd64.deb`, откройте
  терминал в папке с файлом и выполните:

  ```
  sudo apt install ./PRSLOY-…-linux-amd64.deb
  ```

  PRSLOY появится в меню программ. Новую версию ставьте так же, новым файлом .deb.

- **Файл AppImage — без установки, обновляется сам.** Скачайте `PRSLOY-…-linux-x86_64.AppImage`, разрешите
  запуск и запустите:

  ```
  chmod +x PRSLOY-…-linux-x86_64.AppImage
  ./PRSLOY-…-linux-x86_64.AppImage
  ```

  Можно и мышкой: «Свойства» → «Разрешить запуск как программы», потом двойной щелчок.

Node и Python программа приносит с собой. Для кнопки «Откатить» и для «Дизайна» нужен git: если его нет,
поставьте командой `sudo apt install git`. Без git агент работает, но откатить ход не получится.

## Как начать

- **«Дизайн».** Чтобы вкладка заработала, один раз добавьте файл инструментов дизайна. Откройте «Дизайн» →
  «У меня есть файл инструментов» → выберите архив design-pipeline, скачанный с GitHub (Code → Download ZIP).

## Новое

- **Чаты из других программ.** При первом запуске и в «Настройках» можно перенести свои прошлые разговоры из
  Claude Code, Codex, Pi, OpenCode, Gemini CLI и Cursor. Переносится только текст разговора, ключи и пароли
  скрываются. У перенесённого чата есть метка «из Claude Code» (или другой программы), а проект, куда пришли
  чаты, сразу раскрыт в списке слева.
- **Честная строка итога хода.** Если проверки проекта не прошли, над ответом агента появляется красная
  карточка, и агент не пишет «Готово». Строку собирает сама программа по тому, что реально произошло, а не
  со слов модели.
- **Строже проверка в конце хода.** Второе мнение замечает, если агент поменял тесты, а не программу, чтобы
  проверка «прошла», и не даёт выдать это за готовую работу.
- **Ключ спрятан надёжнее.** Внутри программы ключ PRSLOY передаётся напрямую, и другие программы на
  компьютере его не видят.
- **Защита от спрятанных команд.** Невидимые символы и скрытые комментарии на веб-страницах вырезаются до того,
  как их прочтёт агент: так на страницах прячут команды для нейросетей.
- **Код важнее устаревшего описания.** Если описание проекта (AGENTS.md, README) расходится с кодом, агент
  делает как в коде и говорит, где нашёл расхождение. Пока лучше всего это работает с моделью «Быстрее».
- **Память.** Агент сам замечает важное из ваших слов («я бухгалтер», «делай сайты тёмными») и запоминает
  это. Каждый раз он показывает карточку «Запомнил…», и её можно сразу «Вернуть». Забыть или поменять
  запомненное агент может только после вашего «Да». Всё запомненное видно в «Настройках» → «Память», там же
  можно её выключить. В меню чата есть «Забыть всё, что выучено из этого чата».
- **Поиск в интернете.** Агент сам ищет свежие версии программ и документацию: бесплатно, без ключа. Свой ключ
  поиска можно добавить в «Настройках» → «Поиск в интернете», но это не обязательно.
- **Сайт проверяется руками программы.** Когда агент делает сайт, программа сама нажимает кнопки и ссылки,
  отправляет формы и проверяет, можно ли пройти страницу клавиатурой. Найденные ошибки агент чинит сам, а в
  строке итога видно «На странице остались ошибки», если починить не вышло.
- **Модели по умолчанию.** «Быстрее» — deepseek, «Качественнее» — kimi: они точно получают наши указания.
  Остальные модели можно выбрать вручную.
- **Понятнее, когда что-то пошло не так.** «Модель долго не отвечает», «Не скачались пакеты: нет связи»,
  «Программа упала при запуске» — у каждой ситуации своя карточка с кнопкой. Если одна и та же команда падает
  трижды, агент останавливается и объясняет, что не так, вместо бесконечных повторов.
- **Мелочи.** «Новый чат» остаётся в проекте, ответ в старом чате больше не задваивается, после «готово» в
  «Дизайне» главная кнопка — «Скачать архив».

## Подготовлено, но пока выключено

Это уже есть в программе, но выключено, пока мы меряем качество на разных моделях.

- **«Не получилось».** Если агент упёрся во что-то, что сам решить не может, он покажет карточку: что
  мешает и что нужно от вас.
- **Строже к тестам.** Отдельная защита, которая не даёт агенту менять тесты без спроса.
- **Короче системные указания агенту** — пробный вариант, сейчас его сравнивают со старым.

## Что пока не так

- У программы по-прежнему нет цифровой подписи: Windows покажет «Система Windows защитила ваш компьютер».
  Нажмите «Подробнее», потом «Выполнить в любом случае».
- Только Windows 10 и 11.
- Сразу после установки агент может подождать несколько секунд: программа готовит свои инструменты и
  показывает внизу «Готовлю инструменты для агента…». Первый ответ начнётся сам.
- Баланс ключа в программе не показывается.

## Если что-то не так

Напишите владельцу туда, откуда получили установщик: что делали, что ожидали и что увидели, примерное время.
Приложите скриншот, а если просят — последний файл `.jsonl` из папки `%APPDATA%\PRSLOY\agent\sessions`
(ключа PRSLOY в нём нет).
