# STATUS — дорожка UI (W3), ветка `desktop/ui`

## Что сделано

1. **Русский язык** (`lib/locales/ru.ts`, все 1 365 ключей zh + новые). `ru` — язык по умолчанию: `DEFAULT_LOCALE = "ru"`,
   автоопределение даёт `zh` только по китайским сигналам, иначе `ru` (английский — только явным выбором). В настройках
   появился «Русский». Даты и числа идут через `localeTag()`. Захардкоженные развилки zh/en (поиск в карточках, отсчёт
   лимитов) стали ключами. Карточки хода читаются как «Прочитал README.md», «Поправил…», «Запустил…».
   Lockstep-тесты проверяют ключи ru, плейсхолдеры `{var}` и отсутствие «Zeno» в ru.
2. **Бренд PRSLOY.**
   - Палитра в `styles.css`: светлая — бумага #f3eee3, карточка #faf7f0, чернила #3b2a1e, mid #7a6352, линия #ddd2c1,
     ржавчина #a4472c. Тёмная — та же палитра ночью: холст #1c1612, панели #262019, текст #efe6d8, ржавчина #d0714f.
   - Шрифты (OFL, подмножества латиница + кириллица в woff2, `assets/fonts/`, лицензии рядом): Piazzolla для
     заголовков и слова PRSLOY, Geologica для текста, IBM Plex Mono для кода.
   - Монограмма «P.» — контур буквы из Piazzolla, ржавая точка (`build/icon.svg`, `components/PixLogo.tsx`).
     `scripts/render-icons.cjs` растеризует её в `icon.png` (1024), `icon.ico` (16–256) и `icon.icns` (ic07–ic10).
   - Имя PRSLOY: заголовок окна, `app.setName`, «О программе», заставка запуска, html-заголовки, папка
     `Documents/PRSLOY`, сервис хоста, en/zh-строки. Windows AUMID теперь равен appId (`online.prsloy.desktop`), иначе
     панель задач показывала бы чужую иконку. В «О программе» оставлено «основано на Zeno, © 2026 aletheics, MIT»,
     `LICENSE` не тронут.
   - Цвета заголовка окна Windows (titleBarOverlay) и заливка окна — из палитры. Боковая панель по умолчанию сплошная
     (полупрозрачность имеет смысл только с vibrancy на macOS).
3. **Удалены чужие картинки:** `assets/theme-skins/` и два пресета с ними, вместе с тестами. Сохранённый выбор
   удалённой темы откатывается к стандартной. Новые темы в редакторе начинаются с палитры PRSLOY.
4. **Казуальный режим по умолчанию.**
   - Переключатель «Для разработчиков» в «Общих» (выключен по умолчанию, `lib/casual-prefs.ts`). Без него скрыты:
     терминал/TUI (кнопка, хоткей и восстановление режима), «Пакеты» и «Ресурсы» (там же MCP), страницы настроек
     pi, агента, моделей и входа к провайдерам, лимитов, окружения, терминала, рабочих копий, сред и прокси,
     сырой выбор модели и кольцо контекста. Ничего не удалено. Явные слэш-команды (`/model`, `/login`, `/mcp`)
     по-прежнему открывают свои страницы.
   - Вместо выбора модели: «Быстрее | Качественнее». Соответствие — одна константа `MODEL_TIERS` в
     `lib/model-tiers.ts`: fast = `deepseek-v4.1-flash-1017`, quality = `kimi-k3.1-pro`. Провайдер по умолчанию
     `MODEL_TIER_PROVIDER = "prsloy"`. Если хост знает модель под другим провайдером, берётся его запись.
     **Ядру:** поправьте `MODEL_TIER_PROVIDER`, если провайдер шлюза называется иначе.
   - Стоимость в рублях у поля ввода: «ход 1,13 ₽ · чат 1,13 ₽» (`lib/rub-cost.ts`, `components/CostChip.tsx`). Pi
     отдаёт только стоимость сессии в долларах, поэтому стоимость хода — это её прирост за время хода. «Курс ₽ за $»
     в «Общих», по умолчанию 95. Пока ничего не потрачено, плашки нет.
5. **Скриншоты** светлой и тёмной тем, 1280×800: `docs/prsloy/screens/{light,dark}-{1-home,2-chat,3-settings,4-appearance}.png`.
   Источник: `apps/desktop/e2e-screens/screens.spec.ts` (Playwright + Electron, dev-сборка с `ZENO_ISOLATED=1`, временный
   HOME, локальный фейк OpenAI с русским ответом и одним чтением файла). Модели фейка зарегистрированы под провайдером
   `prsloy`, поэтому видно, как работает «Быстрее».

Бюджеты больших файлов не превышены и даже уменьшены: из них вынесены `ResourcesPage`, `EnvironmentSection` и
`ContextUsageIndicator` (main.tsx 4534 → 4476, SettingsPage 5163 → 5109, Composer 1811 → 1758).

## Что не сделано и почему

- **Старый e2e-набор (`e2e/desktop.spec.ts`) не запускал.** Он долгий и проверяет китайский текст. В фикстуре
  закрепил `--lang=zh-CN` и включил режим разработчика, чтобы набор работал как раньше. Smoke-тест ветки ci
  использует только testid, режимы ему не мешают.
- **Перевод вычитан не построчно.** 1 365 строк перевели шесть параллельных агентов по одному глоссарию («агент»,
  «ход», «откатить», «проект», «ключ», «чат»). Я проверил главные экраны, карточки хода, настройки и прогнал скрипт
  поиска английских остатков: остались только технические токены на скрытых страницах для разработчиков (glob-шаблоны,
  `Base URL` → «Адрес API» и т. п.). Живая вычитка носителем полезна.
- **Тема по умолчанию — «как в системе»**, как и было. Обе темы брендовые. Если нужна всегда светлая бумага, это одна
  строка в `loadThemePreference`.
- **Ящик «Разработчик»** внизу боковой панели виден только в неупакованных и тестовых запусках, поэтому он есть на
  скриншотах. В установленном приложении его нет. Он нужен smoke-тесту (`host-status`).
- **Иконки на Windows вживую не видел.** Проверена только структура файлов. На Windows проверит сборка в Actions.
- **Логику провайдера и хоста не трогал.** User-Agent `ZenoDesktop` остался, это зона ядра, и подсказка в ru говорит
  правду. Английское «Agent Host is not ready» приходит из хоста.
