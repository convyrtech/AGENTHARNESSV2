# PRSLOY 0.1.0-alpha.3 — что нового

Третья пробная версия. У кого стоит alpha.2, программа обновится сама: внизу появится «Обновление готово —
перезапустить». Ключ, проекты, чаты и память при этом остаются на месте.

Linux — как в alpha.2: файл `.deb` (Ubuntu, Debian, Linux Mint) или `AppImage`.

## Новое

- **Старые тесты без спроса не меняются.** Если агент видит, что старые проверки в проекте устарели, он не
  переписывает их сам. Он показывает карточку «Тесты устарели» с кнопками «Обновить тесты» и «Оставить как
  есть» — решаете вы.
- **Агент сам запускает проверки на Python.** В программу встроен pytest. Если у проекта есть своё окружение
  (папка `.venv`), агент пользуется им, а если pytest нет — проверяет встроенным способом Python.
- **«Качественнее» не обрывается, когда у поставщика мало денег.** Если на длинный ответ шлюз говорит «не
  хватает средств», программа сама просит ответ покороче и помнит это 10 минут.
- **«Качественнее» без подмены быстрой моделью.** Порядок моделей: Kimi → GPT-6.1 Sol → Opus. Если вы выбрали
  качество, быструю модель вам молча не подставят.
- **Код важнее устаревшего описания — теперь и с моделью «Качественнее».** Если описание проекта (AGENTS.md,
  README) расходится с кодом, агент делает как в коде и говорит, где нашёл расхождение.
- **Поиск в интернете: Tavily и запасные поставщики.** В «Настройках» → «Поиск в интернете» можно добавить
  свой ключ Tavily. Если у выбранного поиска кончился лимит, агент сам переходит к другим поискам, которые вы
  настроили, а потом к бесплатному. В ответе видно, кто искал.
- **Версия программы видна в «Настройках».**
- **«Дизайн»: выбранный для «Править» элемент больше не сбрасывается сам.**

## Как начать «Дизайн»

Как в alpha.2: один раз откройте «Дизайн» → «У меня есть файл инструментов» → выберите архив design-pipeline,
скачанный с GitHub (Code → Download ZIP).
