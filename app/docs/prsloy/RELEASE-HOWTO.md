# Как выпустить версию PRSLOY

1. Дождитесь зелёного **desktop-ci** на кандидате. GitHub → **Actions** → **desktop-windows** → **Run workflow**.
2. Сначала выберите ветку кандидата, следующую версию без «v» (например `0.1.0-alpha.5`) и включите **«Сухой прогон»**. Он проверяет установщик, две Windows, автообновление и файлы выпуска без публикации.
3. После успешного сухого прогона и слияния кандидата выберите **main**, ту же версию и отключите **«Сухой прогон»**. Публикуйте только проверенный состав; новые изменения требуют повторной проверки.
4. Workflow создаст пре-релиз `v<версия>` с Windows-установщиком и файлами обновления. Linux-файлы добавляются отдельным заданием после публикации Windows.
5. Если прогон красный, проверьте конкретное задание и страницу релиза перед повтором: ошибка до публикации Windows обычно оставляет версию свободной, но ошибка добавления Linux-файлов может произойти уже после публикации. Существующую версию нельзя выпускать повторно этим путём.
6. Релиз руками через «Draft a new release» не создавайте: пока он без файлов, обновления у всех стоят. Время сборки зависит от очереди GitHub; завершение подтверждается заданиями и файлами, а не таймером.
