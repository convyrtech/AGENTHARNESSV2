# Как выпустить версию PRSLOY

1. GitHub → **Actions** → слева **desktop-windows** → справа **Run workflow**.
2. Branch: **main**. В поле **version** — следующая версия (без «v», каждый раз новая и больше прошлой; какой ряд — `0.1.0-alpha.N` или `0.2.0-alpha.N` — см. STATUS-ci «Этап 8», п. 4). Галочку **«Сухой прогон»** не ставьте — с ней всё проверится, но ничего не выпустится.
3. **Run workflow**. Через ~18 минут (до ~25, если GitHub занят; сборка → проверки на двух Windows → проверка автообновления) появится пре-релиз `v<версия>` со всеми файлами, и у пользователей придёт обновление.
4. Если прогон красный — ничего не выпущено и тега нет: напишите разработчикам, после исправления запустите снова с той же версией.
5. Релиз руками через «Draft a new release» больше не создавайте: пока он без файлов, обновления у всех стоят.
