## 1. «Выбрать на странице» (§1.5)

**Что видит человек.** В превью «Кода» под шапкой — кнопка «Выбрать на странице». Нажал — элементы страницы
подсвечиваются под мышью. Кликнул — в поле ввода появился блок с точным местом, последняя строка
«Что поменять здесь:», курсор после неё. Человек дописывает «сделай зелёной» и отправляет. Esc — отмена.

**Как устроено.**

- `main/preview-bridge/inspector.js` — скрипт-инспектор, урезанный порт bolt.diy `public/inspector-script.js`
  (MIT): подсветка, клик → `{tag, selector, path, text, html, page}`. `selector` — точный CSS-путь (ближайший
  уникальный `id`, дальше `:nth-of-type`), `html` — первые 300 символов `outerHTML`.
- `main/design/preview-server.ts`: опция `inject`. Только сервер превью «Кода» (`code-preview.ts`) вставляет
  `<script src="/__prsloy/bridge.js">` сразу после `<head>` в ответы `text/html` и сам отдаёт этот скрипт. Превью
  «Дизайна» и серверы, которые поднял агент, не трогаются: там нет скрипта, и кнопки нет.
- `renderer/components/PreviewFrame.tsx` (общий): необязательный `bridge`. Сообщение принимается, только если
  `event.source` — окно нашей рамки и `event.origin` — адрес превью; команды уходят только на этот адрес.
  `renderer/lib/preview-bridge.ts` проверяет форму сообщения и обрезает строки.
- `CodePreviewPanel.tsx`: кнопка появляется, только когда страница ответила `ready`. Блок для поля ввода —
  `pickedPrompt()`; в `main.tsx` он дописывается к черновику.
