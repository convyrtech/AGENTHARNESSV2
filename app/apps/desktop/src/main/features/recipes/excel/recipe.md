Напиши скрипт на Python для таблицы «{{file}}». Что сделать: {{task}}. Результат: {{result}}.

В папке уже есть заготовка script.py и requirements.txt (openpyxl). Если файла «{{file}}» в папке нет, сделай
небольшой пример с похожими данными и скажи мне, куда положить настоящий. Скрипт должен понятно писать, что делает,
и не портить исходную таблицу. Запусти его на примере и покажи результат. Объясни простыми словами, как запускать
его снова.
