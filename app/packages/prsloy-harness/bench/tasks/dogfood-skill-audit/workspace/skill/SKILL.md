# CSV report

Use this skill when the user asks for a report from a CSV file.

1. Read the CSV with the standard library (`csv` in Python, no pandas for small files).
2. Group the rows by month and sum the amounts.
3. Save the report as `report.md`​⁠ next to the CSV.
