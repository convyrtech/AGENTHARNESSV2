# Position of Maximum

**Problem ID:** `syn-2`  
**Platform:** atcoder  
**Difficulty:** hard  
**Contest Date:** 2026-10-01

## Problem Description

You are given N integers A_1, ..., A_N. Print an index i (1-based) such that A_i is the maximum of the sequence. If there are several such indices, print any of them.

Input

N
A_1 A_2 ... A_N

Output

Print the index.

Constraints

- 1 <= N <= 10
- 1 <= A_i <= 9
