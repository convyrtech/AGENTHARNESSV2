# Max Pair Sum

**Problem ID:** `syn-1`  
**Platform:** atcoder  
**Difficulty:** hard  
**Contest Date:** 2026-10-01

## Problem Description

You are given N integers A_1, ..., A_N. Print the maximum value of A_i + A_j over all pairs i < j.

Input

N
A_1 A_2 ... A_N

Output

Print the answer.

Constraints

- 2 <= N <= 10
- 1 <= A_i <= 100
